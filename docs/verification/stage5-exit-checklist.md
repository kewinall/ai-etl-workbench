## 最近可重現缺陷

新建 Task 跨頁草稿：

1. 從專案進入建立 Task，輸入名稱，不提交。
2. 按返回專案設定，再按建立 Task。
3. 實際：未詢問、未阻擋，名稱清空。
4. 預期：有草稿時阻擋離開並說明；提供明確取消草稿後離開方式。
5. 成功建立後應解除草稿保護，不能阻擋正常進入新 Task；提交／上傳中不得任意離開。

修正不可用永久 localStorage 保存機密或檔案內容；不能將模式切換保留
等同跨頁保護。需要覆蓋單檔與雙 CSV，包含目前隱藏的模式草稿。
